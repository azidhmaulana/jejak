# JEJAK bug check ? 19 November 2026

## Scope
API/auth and permissions, registration, CCTV/search, routes, drawing persistence, regions, analytics, earthquakes, hotspots, offline maps, weather layers, and responsive browser flows.

## Fixed
- Invalid Himawari decoder worker messages could throw outside the request promise and crash the API. Invalid results now reject safely; worker exit without a result also rejects. Regression coverage added.
- Shared weather panel CSS could override the compact cyclone panel width. Its selector now retains the intended dimensions.
- The weather rail could cover the Region close button on mobile. Floating panels now have precedence.
- Left rail tools could fall below the viewport on short landscape screens. The rail now scrolls vertically, and the CCTV settings popover remains outside its scroll clipping.
- Wind legend alignment corrected.
- Scalar weather layer installation retries when map style readiness prevented the initial installation.

## Validation
- Production build passed (TypeScript and Vite).
- Unit/server suite: 140 passed.
- Offline-map suite: 25 passed.
- Browser suite: 70 scenarios; 59 passed initially, 10 initially failed, 1 intentionally skipped (hidden daily cloud history). All 10 failing scenarios passed on targeted reruns after fixes and updates to obsolete UI expectations.
- Responsive scenario covered 320, 390, 768, 844 and 1024 px widths, including short landscape screens.

## Limits
Browser tests use fixtures for many upstream feeds. Passing tests do not guarantee external CCTV/provider uptime or every live weather response. Production bundle size warnings remain an optimization item. No production deployment or git push was performed.
