Himawari imagery — JMA

Blue uses RAMMB/CIRA GeoColor Himawari imagery at approximately 1 km native resolution. Daytime imagery shows natural colour; nighttime imagery uses an infrared-based multispectral composite. Source imagery is reprojected to Web Mercator without inventing cloud detail.

Infra uses raw Himawari-9 Band 13 HSD observations published by NOAA (JMA observations). JEJAK calibrates counts into radiance and brightness temperature using each file header, interpolates temperatures in Web Mercator, then applies its own enhanced infrared palette. This is not Windy processing or its palette. Its native resolution is approximately 2 km at the sub-satellite point and decreases towards the limb. Colours show enhanced infrared brightness temperatures, not radar precipitation intensity. Close zooms interpolate the available observations without adding physical detail. Exact observation timestamps are preserved.

True Color Reproduction was developed by JMA's Meteorological Satellite Center with the NOAA/NESDIS/STAR GOES-R Algorithm Working Group imagery team. Rayleigh-scattering correction software was provided by NOAA and CIRA, Colorado State University.

RAMMB/CIRA SLIDER provides the Blue GeoColor imagery.
